
# Contour Shaders

Contour Shaders adds outlines to entities with options to customize how they look, including rainbow outlines.

The main purpose of Contour Shaders was to bring the look of official Minecraft trailers into the game.

Contour Shaders uses Complementary Shaders as a base and injects its own outline code into the shaders, keeping the high-quality look while adding outlines.

The project is still a work in progress, with more goals and features left to complete.

## Contributing

If you're interested in contributing, feel free to open a pull request. Keep these things in mind to make the PR process smoother.

- **Explain your changes.** Describe what your PR does and why it's needed. New features can introduce GPU driver quirks, so explain the reason behind the change.
- **Avoid committing large files when possible.** This makes the code easier to review and the repository easier to manage.
- **No AI-generated code.** AI-generated code is not allowed in this repository. Keep this project as art rather than machine-generated code.
